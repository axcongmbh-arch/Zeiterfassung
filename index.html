Noch kein Supabase? Anleitung anzeigen
1

Auf supabase.com → neues Projekt anlegen → Region EU West

2

SQL Editor → Code ausführen:

create table projects (id text primary key, name text, client text, email text, phone text, rate numeric, budget numeric, color text, created_at timestamptz default now());
create table entries (id text primary key, project_id text, date text, from_time text, to_time text, hours numeric, description text, billable boolean, billed boolean, amount numeric, is_call boolean, created_at timestamptz default now());
alter table projects enable row level security;
alter table entries enable row level security;
create policy "public" on projects for all using (true) with check (true);
create policy "public" on entries for all using (true) with check (true);
3

Settings → API Keys → Legacy anon Key kopieren
